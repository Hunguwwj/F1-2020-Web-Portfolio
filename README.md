🏎️ F1 2020 Web Portfolio - 3D Interactive Archive
Dự án Website lưu trữ và giới thiệu dữ liệu mùa giải Formula 1 (2020) với trải nghiệm không gian 3D tương tác cao. Website kết hợp giữa sức mạnh kết xuất đồ họa của Three.js và khả năng điều phối hoạt ảnh mượt mà của GSAP trên nền tảng Next.js.

🚀 Hướng dẫn cài đặt
Để chạy dự án này trên máy cục bộ, bạn cần cài đặt sẵn Node.js (Phiên bản 18.x trở lên).

1. Sao chép kho lưu trữ (Clone)
Mở terminal và chạy lệnh:

Bash
git clone https://github.com/your-username/f1-2020-web-portfolio.git
cd f1-2020-web-portfolio
2. Cài đặt các thư viện phụ thuộc (Dependencies)
Sử dụng npm hoặc yarn để cài đặt:

Bash
npm install
# hoặc
yarn install
3. Khởi chạy môi trường phát triển
Sau khi cài đặt xong, chạy lệnh sau để bắt đầu:

Bash
npm run dev
# hoặc
yarn dev
Bây giờ, hãy mở trình duyệt và truy cập: http://localhost:3000
